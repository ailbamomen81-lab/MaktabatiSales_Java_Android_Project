# مبيعات مكتبتي — مشروع Android Java

## فتح المشروع وبناء APK
1. ثبّت Android Studio على الكمبيوتر.
2. فك ضغط الملف وافتح مجلد `MaktabatiSales` من Android Studio.
3. اسمح بمزامنة Gradle وثبّت Android SDK Platform 35 عند الطلب.
4. جرّب التطبيق على محاكي أو هاتف أندرويد.
5. لإنشاء APK: من القائمة `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
6. ستجد ملف APK عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## الموجود في النسخة التأسيسية
- قاعدة بيانات SQLite محلية.
- إضافة الأصناف والأسعار والكميات والبحث بالاسم/الباركود.
- تسجيل فاتورة بيع لصنف واحد مع خصم المخزون.
- إنشاء PDF للطباعة على A4 من نافذة الطباعة في أندرويد.
- تسجيل أسماء العملاء والموردين.
- إضافة كميات مشتراة لصنف مسجل.
- تقرير أولي لإجمالي المبيعات ومبيعات اليوم.

## مهم قبل الاستخدام التجاري
هذه نسخة تأسيسية قابلة للتطوير وليست نظامًا محاسبيًا مكتملًا بعد. لم تُنفذ بعد: سلة متعددة الأصناف، فواتير مشتريات كاملة وتكلفتها، المرتجعات، جرد وتسويات المخزون، التقارير الشهرية/السنوية وصافي الربح، التصدير والاستعادة الفعلية للنسخ الاحتياطية، وتسجيل الدخول والصلاحيات. يلزم اختبار المشروع على جهازك ومراجعة الحسابات قبل إدخال بيانات حقيقية.
